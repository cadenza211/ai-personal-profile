# AI 个人档案 · ai-personal-profile

> 一份跨 AI 工具共享的个人档案。目的是让任何一个新的 AI 助手（ChatGPT / Claude / Gemini / Copilot / 本地模型等）在开始工作前，先读懂：**我是谁、我怎么工作、我希望怎么被沟通。**

- 仓库：`https://github.com/cadenza211/ai-personal-profile`
- 维护方式：每次修改提交一次 commit，历史可追溯、可回退（见 [第 7 节](#7-版本与修改记录)）

---

## 使用说明

1. **新会话开场**：把本 README 内容（或仓库链接）直接提供给 AI，作为背景资料。
2. **只写事实**：每条尽量一句话、可验证，不写自我评价式的宣传语。
3. **标注时效**：会变化的信息（职位、项目状态）后面加 `（截至 YYYY-MM）`。
4. **示例条目**：文中以 `> 示例：` 标注的行是占位示范，替换成你自己的内容后可以删掉标记。

## 3. 沟通风格偏好

- **结论优先**：先给结论和下一步，再补理由与细节
- **简洁直接**：不要客套铺垫；不确定就说不确定
- **格式**：要点列表 + 必要示例；代码块给可运行片段
- **反问边界**：信息不足时，先按最合理的默认方案做，并说明假设；只有涉及不可逆操作才先问我
- **语言**：中文为主，技术名词与代码保持英文

> 示例：**结论优先**：回答开头一句话给答案，之后最多 3 条支撑理由。
> 示例：**反问边界**：删数据、发邮件、花钱这类操作，先确认再执行。

## 7. 版本与修改记录

本仓库的每次修改都以 commit 形式记录，完整历史可用 Git 追溯与回退。

- 变更摘要见 [CHANGELOG.md](CHANGELOG.md)
- 提交信息格式：`类型(范围): 说明`，类型如 `feat` / `fix` / `docs` / `chore`
- 回退某次修改：`git revert <commit>`（生成反向提交，保留历史）
- 整体回退到某历史版本：`git reset --hard <commit>`（仅本地、会丢弃之后的提交）
